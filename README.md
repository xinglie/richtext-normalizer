## richtext-normalizer

把复杂的富文本转化为简洁的结构

### 如何使用
在任意网页页面或支持复制富文本的应用中(如 `Visual Studio Code` 编辑器)，复制一段富文本
来到[htts://xinglie.github.io/richtext-normalizer](htts://xinglie.github.io/richtext-normalizer)通过工具栏或 `Ctrl+V` 粘贴。

粘贴后左侧会显示原始富文本，右侧会显示处理过的富文本。

直接 `Ctrl+C` 即可复制走处理好的富文本(不需要拉框选中)，粘贴到相应平台的编辑器里即可。

顶部工具栏可以随意点点，探索下有哪些功能。

### 技术方案

我们采用把字符串结构化、再配合特定标签嵌套和转换逻辑，方便层级调整和任意重构。
我们的程序可以在支持 `javascript` 的环境下运行，纯逻辑和算法，与环境无关。

1. 如果带 `style` 则先解析样式，原子化样式
2. 解析 `HTML` 并把带有 `class` 节点的样式内联化，丢弃 `class` (考虑样式优先级覆盖问题)
3. 丢弃 `style`，当前剩余部分则为初始状态
4. 丢弃所有节点的所有属性
5. 对嵌套的节点进行层级合并，块套块，行内套行内的均进行简化
6. 根据目标支持的不同，以初始状态为参考来源，恢复部分样式并转换节点标签名称
7. 如果目标支持 `style` 标签，则对内联样式进行原子化合并输出

### 微信公众号表格
1. 微信公众号编辑器在编辑表格的时候可以拖动修改列宽
2. 在展示时却删除了所有列宽和表格宽度数据
3. 列数较多的时候会导致挤在一起

在我们右侧预览页面里，支持在表格区域按下鼠标左右拖动改变整体表格的宽度，并支持左右滚动。
能进行一定的表格显示改善。
我们限制了最大宽度为 `3000px`

但是复制到微信公众号编辑器里面的展示和最后发出来的效果是不一样的，这是微信公众号的问题。
如果对表格要求高建议发布前先进行预览。
